# API Automation Framework

## Project Overview

This project is an API Automation Framework developed using Java, Rest Assured, TestNG, Maven, and Cucumber BDD for validating REST APIs.

The framework is designed using reusable components and follows automation testing best practices.

---

* Rest Assured

* Postman
* GitHub
* SQL
* Jira

## Features

* API Request Validation
* API Response Validation
* Status Code Validation
* JSON Response Parsing
* Reusable Utility Methods
* Logging and Reporting
* Data Driven Testing
* BDD Framework Structure
